# AGROSUSTENTAVEL 

O AGROSUSTENTÁVEL é uma plataforma web interativa focada no agronegócio moderno e ecológico. Desenvolvido para iniciativa do concurso Agrinho 2026, o site promove o conceito de "Produzir com Força, Preserva com inteligência", demonstrando como a inovação tecnológica permite aumentar a produtividade no campo sem agredir o meio ambiente.

Pilares da Revolução Verde: Apresenta as três tecnologias base para manejo sustentável:

Sensores e loT: Monitoramento de umidade e nutrientes do solo para evitar desperdício de água e fertilizantes.

Mapeamento por Drones: Identificação de pragas por câmeras multiespectrais, reduzindo o uso de defensivos químicos.

Manejo Regenerativo: Uso de sistemas integrados (como Lavoura-Pecuária-Floresta) para recuperar solos e fixas carbono.

Tecnologias: Apresenta o uso de sensores/loT, drones e manejo regenerativo (ILPF) para produzir preservando.

Métricas: Mostra um grafico qque comprova o aumento da produtividade sem a expansão da área de terra.

Simulador: Um quiz onde o usuario age como gestor agrícola, tomando decisões sustentáveis para equilibrar lucro e conservação.
